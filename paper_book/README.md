    - **Core Idea:** multimodal dataset curated specifically for analyzing the Chinese stock market

    - **Core Idea:** fuses Q-learning and dynamic programming to to take advantage of the structural features of order book trade execution

- **FactorMiner: A Self-Evolving Agent with Skills and Experience Memory for Financial Alpha Discovery**
    - **Domain:** LLM agent
    - **Core Idea:** self-evolving discovery loop: retrieve, generate, evaluate, and distill
    - **Link to Paper:** [paper](https://arxiv.org/pdf/2602.14670v1)

- **Spatio-Temporal Wavelet Enhanced Attention Mamba for Stock Price Forecasting**
    - **Domain:** spatiotemporal time series 
    - **Core Idea:** Discrete Wavelet Transform (DWT) for disentangling multi-frequency temporal features, Wavelet Enhanced Attention (WEA) for capturing cross frequency spatial dependencies, Mamba-2 architecture to extract the synergistic spatio-temporal dependencies in stock data.
    - **Link to Paper:** [paper](https://dl.acm.org/doi/pdf/10.1145/3746252.3761399)

- **Yau's Affine-Normal Descent for Large-Scale Unrestricted Higher-Moment Portfolio Optimization**
    - **Domain:** numerical optimization
    - **Core Idea:** The method avoids explicit higher-order tensors and exploits the quartic structure for exact sample oracles, derivative evaluation, and exact line search. The algorithm is based on Yau's affine-normal descent that follows affine-normal directions of the current level set while working directly with the return matrix.
    - **Link to Paper:** [paper](https://arxiv.org/pdf/2604.25378)
    <!-- - **Implementation Status:** xxx -->

- **TradeTrap: Are LLM-based Trading Agents Truly Reliable and Faithful?**
    - **Domain:** evaluation framework, benchmark
    - **Core Idea:** a unified evaluation framework for systematically stress-testing both Adaptive and Procedural autonomous trading agents. targets four core components of autonomous trading agents—market intelligence, strategy formulation, portfolio and ledger handling, and trade execution.
    - **Link to Paper:** [paper](https://arxiv.org/pdf/2512.02261), [code](https://github.com/Yanlewen/TradeTrap)
